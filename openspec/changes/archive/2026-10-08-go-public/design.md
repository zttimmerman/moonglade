## As built (builder, 2026-10-08)
- **Scanner:** `harness/hslib/publicscan.py` (also a CLI: `python3 -m hslib.publicscan tree|history <repo>|files <f>...`). Built-in patterns: non-noreply/example emails, `/Users/<name>/` paths, Claude Code session URLs (personal), "private repo" / "never redistribut…" (wording, tree only, allowlisted only inside this change's own files). Denylist lines are literal and case-insensitive. Hits name file, line and "denylist #N", never the matched text.
- **Missing denylist:** required only when the untracked marker `env/public-denylist.required` exists (missing or empty → `DenylistError`, fail-closed; the marker is on Zach's Mac next to the denylist). Without the marker and without a denylist (a friend's clone), the denylist part is skipped, the built-in patterns still run, and the evidence carries `denylist_note`. Tests pass `marker=` (a path) like `denylist=`.
- **Tree scan input:** every index entry, read from the working-tree file (edits included) or, when it's only in the index, from its staged blob. The self-test stages its plant in a temporary index with a temporary object directory, so the repo's index and object store aren't touched.
- **Rewrite:** `tools/go-public/mirror.sh` (real `git clone --mirror` of origin, push URL set to `no-push`), `rewrite.sh` (pinned git-filter-repo 2.47.0 by hash into `env/tools/venv`), `rewrite.py` (git-filter-repo as a library: email, message, blob and filename callbacks; refuses non-bare targets, this checkout's git dir and any GitHub push URL before touching anything). Blob redaction runs on every blob, binary ones included (git-filter-repo's `--replace-text` skips binaries).
- **Checks:** `public.license`, `public.tree_scrub`, `public.no_game_files` (quick, file-only); `public.history_dryrun` (slow: it needs the network for the mirror clone and origin). The dry run compares the rewritten tree of the *current branch* (which must be pushed at HEAD) with this checkout's HEAD tree, and reports `main` before/after too.
